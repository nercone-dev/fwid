# FWID (FourWord Identifier)
時系列でソート可能な、新しいランダム識別子の生成方式

## 概要
FWIDは、データベースの主キーなどの用途を想定して設計されたランダムな識別子です。

長さは可変で、32ビットの任意の倍数を指定できます。2026-11-04時点では192ビットが推奨される長さです。

```
[ タイムスタンプ: 全体のビット数 / 4 ] + [ CSPRNG出力: 全体のビット数 / 4 × 3 ]
```

タイムスタンプは2001-01-01 00:00:00 UTCからの経過ミリ秒数です。固定長ではなく全体の4分の1を占めるため、IDを長くするほどタイムスタンプがオーバーフローするまでの期間も長くなります。トレードオフとして、タイムスタンプの先頭のゼロが増えます。

## フォーマット

| フォーマット | エンコード | 例(192ビット) |
|---|---|---|
| 標準テキスト | Base32 Hex、パディングは `Z` | `00NNTHJS00TETRA0QEQOA000000000001LISHPGZ` |
| 可読テキスト | Crockford's Base32、小文字、パディングなし、8文字ごとにハイフン | `00qqxhkw-00xexva0-tetra000-00000000-1njwhsg` |
| コンパクトテキスト | Base62、固定長 | `007h3WQ0lRIoEEs6MANGd9PJQhKTtetra` |

ビット長、構造、オーバーフローの規則、各テキストフォーマットとそのパース規則、衝突確率、オーバーフローの時期などの詳細な仕様は[SPEC.ja.md](SPEC.ja.md)を参照してください。

## 名前の由来
"Four" は、タイムスタンプがビット長の1/4を占めることに由来します。
また、英単語の "Forward" にちなんだ言葉遊びでもあります。

## 実装
Python(`src/fwid`)に加え、Rust・Go・Swift・JavaScript・Lythonコンパイラ向けの実装を同梱しています。いずれも同じコマンドラインツールを備えています。詳しくは[docs/implementations.md](docs/implementations.md)(英語)を参照してください。
